# PSKA Browser Demo Note

PSKA is an external cognitive system for source-first, memory-governed agent work.

The demo should show that Hermes does not answer broad project questions from vibes alone.
It first asks PSKA for an Agentic Context Brief that combines source recall, durable Memory
Cards, trace signals, and next actions.

Key functional points:

- Source Recall uses local files and no-embedding search before answer generation.
- Agentic Ask checks scope readiness, retrieves evidence, reads source context, and prepares a transient work product.
- Memory Governance keeps durable memory behind Memory Cards, Review, quality gates, and lifecycle trace.
- Trace explains why a source, memory, review, or workflow exists without claiming hidden model causality.
- Eidolia contributes thought and artifact references while keeping the visible canvas model simple.

For this demo, the important conclusion is that PSKA is not just a slide-deck idea.
The browser UI should show live buttons, API-backed cards, recent context brief recovery, and audit-backed activity.

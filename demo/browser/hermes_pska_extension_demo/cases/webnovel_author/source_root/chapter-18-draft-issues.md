# Chapter 18 Draft Issues

Case type: fictional webnovel demo.

## Draft Situation

第 18 章草稿中，沈照夜在旧潮汐塔发现一枚能打开星图的铜针。岑青砚告诉他铜针来自云台司密库，并催促他立刻离开。

## Detected Conflicts

1. 岑青砚直接说“我骗了你”，这违反了 story bible 中“她不能直接说谎”的约束。
2. 草稿把星图写成能击碎城墙的武器，违反了“星图是导航和记忆装置”的核心规则。
3. 章末只有“云海深处传来低语”这种气氛悬念，没有留下具体问题。
4. 陆怀砂本章只负责插科打诨，没有发挥“记录矛盾”的功能。

## Rewrite Direction

- 让岑青砚用沉默、停顿和物件动作暗示秘密。
- 把铜针写成校准星图记忆层的工具，而不是武器钥匙。
- 让陆怀砂发现岑青砚对“密库”的称呼前后不一致。
- 章末问题可以是：铜针记住的是谁的航线，为什么它指向已经沉没的城邦？

# Webnovel Case: 网文作者与写手创作

这是 PSKA + Eidolia 功能演示用的拟真网文创作案例资料包。

目标用户：网文作者、写手、编辑、剧本/世界观创作者。

演示问题：

```text
请基于 PSKA 当前 scope，帮我检查《云涯纪》第 18 章续写：
1. 当前草稿和设定有什么冲突？
2. 哪些读者反馈应该影响下一章？
3. 哪些风格偏好应进入长期记忆 review？
4. Eidolia thought/artifact 如何变成可追溯的创作上下文？
```

PSKA 演示点：

- Source Recall：从 story bible、章节问题、读者反馈中查找证据。
- Eidolia bridge：把 thought/artifact 作为可引用上下文，而不是新增复杂节点类型。
- Memory Review：把作者风格偏好变成可审核 Memory Card。
- Trace：保留“设定 -> 草稿冲突 -> 修改建议 -> 记忆候选”的链路。

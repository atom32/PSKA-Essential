# Eidolia Story Bible: 云涯纪

Case type: fictional webnovel demo.

## Core Premise

《云涯纪》是东方奇幻长篇。主角沈照夜在云海边境修复失落的星图，同时发现自己的师门曾经篡改过天象记录。

## Current Rules

- 星图不是武器，而是导航和记忆装置。
- 云海中的城邦依靠潮汐钟判断航线。
- 女主岑青砚不能直接说谎，但可以用沉默和转移话题保护秘密。
- 反派云台司不应被写成纯恶势力；他们相信篡改天象能避免战争。
- 每章结尾要留下一个具体问题，而不是只用气氛悬念。

## Character Anchors

沈照夜：行动快，但做重大决定前会先确认一个旧物证。

岑青砚：语言克制，喜欢把情绪压到动作细节里。

陆怀砂：看似轻浮，实际在记录每个人说话中的矛盾。

## Style Anchors

- 少用宏大空话，多用可触摸的物件。
- 打斗要服务于信息揭露。
- 章节推进优先靠选择和代价，而不是突然出现的新设定。

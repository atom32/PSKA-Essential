# Finance Case: 财报调研与经营管理

这是 PSKA 功能演示用的拟真案例资料包，不构成投资建议，也不对应真实上市公司。

目标用户：金融分析师、投研人员、CFO 办公室、公司经营管理者。

演示问题：

```text
请基于 PSKA 当前 scope，帮我做 Northstar Robotics 2026 Q2 的财报调研：
1. 业绩变化的核心原因是什么？
2. 有哪些经营风险值得追问？
3. 管理层下一步应该做什么？
4. 哪些结论应进入长期记忆或 review？
```

PSKA 演示点：

- Source Recall：从本地财报笔记、风险登记、管理 action ledger 中找证据。
- Agentic Context Brief：把 evidence、memory、trace、next actions 组装给 Hermes。
- Memory Review：把稳定的分析偏好和经营跟踪规则变成 Memory Card candidate。
- Trace：保留“财报资料 -> 分析判断 -> review/action”的链路。
